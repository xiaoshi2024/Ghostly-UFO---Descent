# Ghostly UFO Descent
Ghostly UFO Descent是一款基于Minecraft 1.21.10和NeoForge的模组，融合了神秘的灵魂探索、多维度冒险和独特的作物系统。这个模组带您进入一个充满超自然现象和未知领域的世界。

## 模组特性
### 1. 灵魂状态系统
- 玩家可以进入灵魂状态，在不同维度间体验独特的游戏机制
- 在梦境世界中，灵魂状态可见且可受到伤害
- 在主世界或其他维度中，灵魂状态会变得隐身且无敌
- 死亡后会根据灵魂状态和所在维度产生特殊的复活机制
### 2. 极噬种子种植系统
- 种植机制 ：极噬种子可以种植在多种土壤上，包括普通泥土、耕地、草方块、灰化土、菌丝、灵魂土、泥巴和泥泞的红树根
- 生长特性 ：成熟的极噬种子会触发特殊事件
- 收获系统 ：玩家右键成熟的极噬种子时会生成孢子星人，并使成熟植物消失
- 自动生成 ：如果玩家不干扰，成熟的极噬种子有30%几率在30秒后自动生成孢子星人
### 3. 多维度探索
- 梦境世界 ：一个神秘的平行维度，提供独特的探索体验和视觉效果
- 安全传送 ：实现了梦境维度的安全传送机制，防止玩家迷失
### 4. 特殊实体
- 孢子星人 ：由成熟的极噬种子生成的特殊生物
- 覆灵者 ：继承了玩家外貌的特殊实体，由玩家通过鬼怪卷轴化形
- 极噬者UFO ：强大的Boss级实体
- 陨石实体 ：特殊的环境实体
- 玩家尸体 ：记录玩家状态的特殊实体

### 核心事件处理器
1. PhagenaHarvestHandler
   
   - 处理极噬种子成熟时的收获事件
   - 实现玩家右键交互生成孢子星人
   - 管理自动生成孢子星人的概率机制（30%几率，30秒间隔）
   - 优化的成熟作物跟踪系统，使用Map和Set高效管理多个维度的成熟作物
   - 实现方块状态变更监听和区块加载状态检查
2. CropPlantingHandler
   
   - 处理极噬种子的种植逻辑和右键交互事件
   - 验证种植条件和合适的土壤类型
   - 实现种植音效和物品消耗机制
3. SoulStateHandler
   
   - 管理玩家的灵魂状态和维度切换处理
   - 实现特殊的死亡和复活机制，在梦境世界死亡时传回主世界
   - 根据维度动态调整玩家的可见性和无敌状态
   - 包含玩家登录和重生时的状态恢复功能
## 游戏玩法
### 极噬种子种植指南
1. 获取极噬种子
2. 找到合适的土壤（泥土、耕地等多种类型）
3. 右键点击土壤进行种植
4. 等待种子成熟
5. 成熟后可选择：
   - 右键点击手动收获并生成孢子星人
   - 等待30秒，有30%几率自动生成孢子星人
### 灵魂状态探索
1. 通过幽灵卷轴进入灵魂状态
2. 使用幽灵石棺记录你的肉身位置
3. 探索梦境世界，体验不同的游戏规则
   - 在梦境世界中，灵魂状态可见且可受到伤害
   - 注意梦境世界的特殊视觉效果和氛围
4. 在梦境世界中死亡时，你会自动传回主世界的石棺位置
5. 利用灵魂状态在主世界中隐身探索和规避危险
### UFO与Boss挑战
1. 寻找UFO方块，它可能是通往特殊区域的关键
2. 面对极噬者UFO，这是一个强大的Boss挑战
3. 注意躲避陨石实体的攻击
## 模组物品详解
### 核心物品
1. **幽灵卷轴 (Ghostly Scroll)**
   - 用途：拿在副手激活，释放覆灵技能
   - 特性：有100点耐久度，每次使用消耗20点
   - 动画效果：使用时会播放打开动画
   - 获取方式：与孢子星人互动，或在特殊结构中发现

2. **极噬种子 (Phagan Seeds)**
   - 用途：种植极噬植物
   - 特性：可在多种土壤上生长
   - 动画效果：手持时有动画效果
   - 获取方式：探索或击败特定实体

3. **幽灵石棺 (Ghostly Sarcophagus)**
   - 用途：记录玩家肉身位置，作为灵魂返回的锚点
   - 特性：极高的硬度和爆炸抗性（黑曜石级别）
   - 获取方式：玩家第4天生存时间降临的飞碟残骸的一部分

4. **UFO方块 (UFO Block)**
   - 用途：维度传送门，用于玩家回到主世界
   - 特性：极高的硬度和爆炸抗性
   - 获取方式：探索或制作

### 核心方块
1. **极噬植物 (Phagenabotanys)**
   - 生长阶段：多阶段生长，成熟后可收获
   - 收获效果：生成孢子星人
   - 自动生成：30%几率在30秒后自动触发

## 技术实现细节
### 事件系统
- 使用NeoForge事件总线注册和处理各种游戏事件
- 实现了玩家交互、方块更新、世界tick和实体死亡等关键事件的监听
- 采用服务端安全检查，确保实体生成和方块操作只在服务端执行
### 性能优化
- 采用延迟检查机制，避免频繁计算影响游戏性能
- 实现区块加载状态验证，只处理已加载区块中的方块
- 使用哈希映射和集合高效管理多维度的成熟作物数据
- 采用交错检查时间，防止大量计算同时发生
### 动画系统
- 集成GeckoLib 5实现流畅的3D动画效果
- 方块、实体和物品都有自定义动画
- 服务端动画同步机制
